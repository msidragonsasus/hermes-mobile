# Product Requirements Document

## 1. 製品仮称

**Personal AI Shell**

「AIと会話するアプリ」ではなく、
**自分のAIエージェントを日常的に運用するためのモバイル操作面**と定義する。

## 2. 問題

一般的なチャットUIでは、次の問題が残る。

- 毎回どのチャット・どの文脈を使うか人間が判断する
- 長時間実行を離れた後、何が起きているか分からない
- 承認・質問・エラーが会話ログに埋もれる
- 就活、大学、開発などの固有UIを追加しにくい
- エージェントの管理画面と日常操作が混在する
- スマホの共有、通知、カメラ、音声を十分使えない

## 3. 製品目標

### P0: 必須

1. アプリ起動後、最短で新しい依頼を送れる
2. 実行中・人間待ち・完了・失敗を一目で識別できる
3. 承認・質問に通知から2タップ以内で応答できる
4. Hermesのセッションと実行状態を継続表示できる
5. 就活等の機能を独立したMini Appとして追加できる
6. 接続断やHermes再起動で、UIが無言で壊れない
7. 高影響操作は人間の明示承認なしに実行しない

### P1: 重要

- Android共有メニューからURL・テキスト・ファイルを送れる
- 音声入力、画像、カメラを使える
- 自宅外でもTailscale経由で安全に利用できる
- 通知から承認、停止、再開を行える
- Mini Appごとの権限とデータ範囲を確認できる
- ローカルキャッシュで履歴と進捗を素早く表示できる

### P2: 将来

- ホーム画面ウィジェット
- Quick Settings Tile
- 信頼できるPush経路
- 複数Hermes gateway
- タブレット/折りたたみ最適化
- iOSクライアント
- Mini App署名・配布カタログ

## 4. 対象ユーザー

初期版は単一ユーザー専用。

### 主な利用領域

- 就活: 締切、企業研究、ES、面接準備
- 大学: 課題、論文、分析、提出物
- 開発: GitHub、Codex、テスト、バグ対応
- 日常運用: 今日やること、通知、ファイル整理
- 投資: 調査と反証のみ。発注は対象外

## 5. Jobs To Be Done

### JTBD-1: 雑に依頼する

「思いついた瞬間に、分類や設定を考えず依頼したい」

成功条件:
- 起動直後に入力欄へフォーカスできる
- 送信前に高度な設定を要求しない
- 自動ルーティングが基本で、必要時だけ手動変更できる

### JTBD-2: 放置して戻る

「長い処理を任せ、後から状況だけ確認したい」

成功条件:
- Chatを開かなくてもActivityで把握できる
- 現在の段階、待ち理由、経過時間が分かる
- 実行を停止・追加入力・再開できる

### JTBD-3: 人間判断にだけ集中する

「AIが止まった理由と、何を決めればいいかだけ知りたい」

成功条件:
- Todayの先頭にNeeds Youを表示
- 承認カードに対象、影響、差分、期限を表示
- 承認、修正、拒否が明確

### JTBD-4: 固有業務をアプリ化する

「就活や大学を、毎回チャットで説明せず専用画面から進めたい」

成功条件:
- Appsから機能を追加・固定・並べ替え可能
- Mini AppがTodayカードやグローバルコマンドに貢献できる
- Mini Appは必要な権限だけを要求する

## 6. 主要情報モデル

### Session

会話の継続単位。Hermes側を正本とする。

### Run

1回の実行単位。バックグラウンド実行、ツール呼出、承認、結果を含む。

### Attention Item

人間の入力が必要な項目。

- Approval
- Clarification
- Secret request
- Sudo request
- Error requiring action
- Expiring request

### Mini App

特定の目的を持つ機能単位。

- Native
- SDUI
- Web

### Contribution

Mini AppがホストUIに差し込む要素。

- Todayカード
- コマンド
- Composer action
- Activity renderer
- 設定セクション
- 通知ルート

## 8. 非機能要件

### 速度目標

保証値ではなく設計目標。

- コールドスタート: 対象端末で2秒以内
- 入力送信からローカル表示: 100ms以内
- ストリーミング描画: 32–50ms単位にバッファし、過剰再コンポーズを避ける
- 通知から対象カード: 2タップ以内
- 新規依頼開始: アプリ起動後1タップ＋入力

### 信頼性

- WebSocketは指数バックオフで再接続
- 接続状態を常時表示
- 送信結果不明を「失敗」と断定しない
- idempotency keyを用意する
- 再接続時にserver-side stateを再同期
- 古いオフライン依頼を自動送信しない

### アクセシビリティ

- 48dp以上のタッチ領域
- TalkBackラベル
- 色だけで状態を表現しない
- フォント拡大に耐える
- 動きを減らす設定を尊重
- 日本語の長文と英数字・コード混在に耐える

### プライバシー

- 外部テレメトリは初期状態で無効
- 認証情報をログへ出さない
- ローカルDBは暗号化
- Mini Appごとの権限を表示
- 機密値はMini Appへ直接渡さない

## 9. 初期Mini App

### Personal Ops

Todayのデータ構成と、日常のクイックアクション。

### Career

締切、企業、ES、面接準備、提出前チェック。

### University

課題、資料、研究、分析実行。

### Development

Repository、Issue/PR、Codexジョブ、テスト結果。

### Investment

P2以降。調査・反証・監視に限定し、注文機能は持たせない。

## 10. 非目標

- HermesそのものをAndroid側で再実装しない
- 自動売買をしない
- ユーザー承認なしでメール送信・応募・公開・mergeをしない
- 任意の外部Nativeコードをダウンロード実行しない
- 初期版で第三者向けMini App Storeを作らない
- 初期版で複数人の組織利用を扱わない
