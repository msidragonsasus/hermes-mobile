## 保存互換性

- `GET /companies/{id}` に既存 `company_links` の `links` 配列を追加。クライアントの既定値は空配列。登録URLの表示には対応するサーバーコードも必要。
- マイページリンクは公式採用URLと別のレコード。HTTPS URL・対象企業・版番号を検証し、他企業へのリンク移動は拒否する。
- ログインIDは接続先・プロファイル・企業別の暗号化端末保存。新しい保存キーがなければ従来のアカウント記録を読む。空配列の保存により削除したIDが再出現することを防ぐ。サーバー・GitHubへのID送信は追加しない。
- 未完了の取り込み操作は通常の保存状況として再確認・再試行の取りやめが可能。新規取り込みの入口は提供しない。
- DBの破棄、アプリのアンインストール、実機更新、サーバー更新、pushは行わない。
