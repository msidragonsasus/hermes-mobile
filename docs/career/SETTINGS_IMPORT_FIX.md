## 変更

- 設定画面を独立したスクロール領域へ整理。取り込み復旧、データ取り込み、同期、自動調査、利用停止を区別し、記録一覧の空状態を設定に表示しない。
- 画面タイトルと選択中の「相談・記録・設定」を一致させた。取り込み内訳は日本語で表示し、保留内容を展開できる。
- 企業一覧のマイページ認証を除去。日鉄エンジニアリングの対象詳細にAXOLへの入口を限定。認証の保存失敗時には入力を保持する。
- メール・AXOL取得をAPIのchannelで分離。旧サーバーには個別設定を送らず、対応版への更新を表示する。
- 転送ファイルの固定日付案内を除去し、選択ファイル名を表示。ファイル選択をキャンセルしても元の選択を失わない。
- サーバーの取り込み拒否を容量エラーと混同せず表示。元の操作ID・ペイロードを保持し、更新後の同一操作再試行を検証。
- 取り込み成功時は追加・変更なし・確認が必要な件数を表示。
- サーバー配布allowlistへ不足していたメールモジュールと回帰テストを追加。
