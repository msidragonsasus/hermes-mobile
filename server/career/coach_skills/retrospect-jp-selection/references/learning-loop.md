# 選考学習ループ

## 分ける

- CONFIRMED: 質問、回答、時間、形式、直接のフィードバック、結果
- INFERRED: 不合格・通過に関する原因仮説
- UNKNOWN: 面接官の評価、競争状況、採用枠など確認不能な事項

## 仮説の扱い

仮説ごとに、根拠、反証、信頼度、次回の検証方法を持つ。単一の合否だけでプロフィールや能力評価を確定変更しない。直接フィードバック、複数回の再現、録音・メモなど証拠が強い場合に信頼度を上げる。

## 変える対象

- 次回の回答構造
- 企業研究の不足
- 経験の証拠不足
- 応募先・選考時期の配分
- 練習方法
- 行動量と締切管理

「もっと頑張る」ではなく、次回に観測できる変更へ落とす。
