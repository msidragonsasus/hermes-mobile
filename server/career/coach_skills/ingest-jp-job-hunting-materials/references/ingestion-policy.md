# 就活資料取り込みポリシー

## 対象

過去ES、履歴書、自己分析、面接メモ、企業一覧、応募台帳、チャット書き出し、就活メールの貼り付け、PDF・表計算等。

## 手順

1. ファイル・資料ごとに出所、対象年度、企業・コース、更新日、本人作成か外部資料かを識別する。
2. 本人事実候補、清書表現、外部企業情報、応募状態、選考観測、第三者PIIを分離する。
3. 清書案にしかない数字・感情・因果は `CONFIRMED` にしない。
4. 矛盾を消さず、候補値と出典を並べる。
5. 既存IDとの重複を調べ、追加・更新・保留を分ける。
6. 保存は状態パッチのプレビューで示す。

## 禁止

- 過去ESの文章を事実台帳として丸ごと確定すること
- メール本文や第三者連絡先を無断保存すること
- ファイルを読めていないのに取り込んだと扱うこと
- 同名企業・別年度・別コースを一案件へ統合すること
