# 就活連絡文ガイド

## 必要情報

- 宛先と関係: 採用担当、社員、OB・OG、大学、紹介者
- 目的: 訪問依頼、日程調整、お礼、辞退、問い合わせ、遅延・欠席連絡
- 初回か返信か
- 候補日時、タイムゾーン、場所・形式
- 名乗りに必要な所属・氏名
- 既に伝えた内容、避けたい表現

## 原則

- 宛先名、会社名、役職、日時を創作しない。未確認は `[要確認]` とする。
- 件名で目的と本人を識別できるようにする。
- 初回連絡では、名乗り、連絡理由、依頼、候補、相手への配慮、署名を簡潔に置く。
- 返信では既出情報を繰り返しすぎない。
- 敬語を重ねすぎず、相手が次に何をすればよいか明確にする。
- 「御社」は話し言葉、「貴社」は書き言葉として扱う。
- 相対日付だけでなく、絶対日付と曜日を確認する。
