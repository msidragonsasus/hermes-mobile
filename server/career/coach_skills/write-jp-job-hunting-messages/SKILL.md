# 就活の連絡文を作る

## 読むもの

`references/question-policy.md`、`references/privacy-policy.md`、`references/message-guidelines.md`

## 手順

1. 宛先、関係、目的、初回か返信か、候補日時、名乗り、署名、既出内容を確認する。
2. 返信で接続メールを使う場合は、対象スレッドを必要範囲で先に読む。宛先や文脈を推測しない。
3. 不足が本文を大きく変える場合だけ最大3問する。安全な箇所は `[要確認]` で暫定案を作る。
4. 相対日付を絶対日付へ直し、曜日とタイムゾーンを確認する。
5. 相手が読む順に、件名、名乗り、要件、依頼、候補、配慮、署名を置く。
6. 過剰敬語、長い前置き、謝罪の重複、判断丸投げを減らす。
7. 「添削」では元文の意図と温度感を維持する。
8. デフォルトは下書き。送信、転送、CC/BCC、添付は本人が明示した場合だけ実行する。

## 出力

1. **件名**
2. **本文**
3. **要確認箇所**
4. **送信前チェック**
5. **実際の送信結果**（明示依頼で実行した場合のみ）

日時、宛先、会社名、役職を創作しない。
