# 日本語ESを提出前校正する

## 読むもの

`references/evidence-policy.md`、`references/question-policy.md`、`references/proofread-policy.md`

## 手順

1. 設問、字数、本文、文体、禁止文字、変更禁止範囲を確認する。
2. 誤字脱字、表記揺れ、助詞、主述、係り受け、句読点、明白な重複だけを直す。
3. 字数超過時だけ、意味を保って圧縮する。内容改善を黙って混ぜない。
4. 補助スクリプトが実行可能なら、このSkillの `scripts/count_chars.py` で複数方式の文字数と禁止文字を確認する。
5. 原文と校正後を比較し、主張、事実、因果、役割、企業・コースが変わっていないことを確認する。
6. 内容面に重大な問題があっても、本文へ勝手に修正を混ぜず別枠で指摘する。

## 出力

1. **校正後本文**
2. **文字数と計測方式**
3. **意味に影響し得る修正**
4. **内容面の重大な要確認**（最大2点）

本文だけを求められた場合は、校正後本文と文字数を優先する。
