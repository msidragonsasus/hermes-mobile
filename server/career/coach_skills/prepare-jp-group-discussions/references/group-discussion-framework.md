# グループディスカッション・フレームワーク

## 標準プロセス

1. お題、目的、対象、期間、制約を確認
2. 暫定の評価軸と論点を置く
3. 発散して選択肢・根拠・リスクを集める
4. 評価軸へ戻して比較する
5. 反証と実行条件を確認する
6. 結論、理由、留保、次の検証をまとめる
7. 発表形式へ圧縮する

時間配分は固定比率ではなく、発表時間、資料量、参加人数に応じて調整する。

## 観測軸

- **回答性**: お題へ直接答えているか
- **構造**: 論点と評価軸が共有されているか
- **根拠**: 事実、仮定、推論を分けているか
- **傾聴**: 他者の意見を正確に受け取っているか
- **接続**: 意見を統合・比較・反証できるか
- **修正**: 新情報で立場や進め方を更新できるか
- **時間**: 発散と収束の配分を管理できるか
- **伝達**: 結論と理由を簡潔に共有できるか

「発言量が多い」「司会をした」だけを高評価の根拠にしない。
