# ES品質ゲート

点数より、提出リスクを優先する。

## 致命的（提出停止）

- 設問に答えていない、別企業・別コースの内容が混じる
- 未確認の数字、役割、発言、感情、成果、因果が入る
- 本人とチームの成果が混同される
- 他の提出項目や確認済みプロフィールと明確に矛盾する
- 文字数、禁止文字、必須条件を満たさない

## 重大（要修正）

- 結論はあるが、本人の判断や役割が見えない
- 行動の羅列で、なぜその手段を選んだか分からない
- 結果と行動の因果が過大である
- 志望動機が企業説明のみ、または企業名を変えて成立する
- 学びが抽象語だけで、次の行動へ接続しない
- 背景が長く、設問が求める部分の字数が不足する

## 軽微（提出可だが改善余地）

- 同じ語尾、冗長表現、指示語の多用
- 抽象語の一部、文の長さ、読点の過不足
- 上限に余裕があるが、追加しても情報価値が低い箇所

## 設問別の中心

- ガクチカ: 課題、本人の役割、判断、行動、変化
- 自己PR: 一貫した行動特性、根拠、別場面での再現性
- 志望動機: 本人側の起点、業界、企業固有性、職種・機会、確かめたいこと
- 困難・挑戦: 難しさの理由、停滞、修正、継続
- チーム: 関係者、利害、調整、組織への影響
- 学業・研究: 問い、方法、本人の論点、得た視点

同じ経験を複数設問で使うこと自体は減点しない。設問ごとの主張と証拠が重複し、候補者像の情報量が増えていない場合にだけ改善対象とする。
