# 業界・職種による補助観点

企業固有の公式情報と設問要求を先に確認し、その後に補助的に使う。業界名だけから採用基準を断定しない。

- 商社・鉄鋼・素材・大手BtoB: 信頼形成、利害調整、現場での継続、関係者を動かす過程
- SIer・IT: 利用者の課題、要件整理、技術を手段として使った判断、改善検証
- インフラ・エネルギー: 利用者・地域、安定性、長期責任、現場理解
- 銀行・信託: 相手事情の理解、信頼、長期関係、堅実さと変化対応
- コンサル: 問いの設定、仮説、根拠、検証、修正。行っていない分析を後付けしない
- BtoBメーカー: 顧客価値、技術・事業への具体的関心、部門間協働、実行可能性

企業の「求める人物像」の語句を貼り付けず、本人の具体行動との接続を示す。
